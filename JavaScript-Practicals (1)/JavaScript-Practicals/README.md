## Run the JavaScript files

1. Install [Node.js](https://nodejs.org/).
2. Open a terminal in the required lab folder.
3. Run:

```bash
node script.js
```

**Browser tasks:** Some tasks in Lab 1 and Lab 9 use browser features such as `document` and `localStorage`. Run those tasks in a browser page with the required HTML elements, rather than directly in Node.js.
